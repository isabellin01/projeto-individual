# 🎮 GameLoop
GameLoop é uma plataforma de fórum voltada para entusiastas, estudantes e desenvolvedores de jogos que desejam compartilhar conhecimento, tirar dúvidas e acompanhar tendências sobre o desenvolvimento de games. O projeto foi desenvolvido como parte de um trabalho acadêmico, unindo conceitos de desenvolvimento web, banco de dados e análise de dados.

## 📌 Objetivo do Gameloop
O objetivo do GameLoop é criar um ambiente colaborativo onde usuários possam:  
• Criar tópicos com perguntas ou discussões sobre desenvolvimento de jogos  
• Responder e interagir com outros membros da comunidade  
• Acompanhar os tópicos mais comentados  
• Visualizar KPIs e métricas importantes do fórum por meio de uma dashboard  

## 🧩 Funcionalidades
👤 Cadastro e autenticação de usuário  
💬 Publicação e resposta de tópicos no fórum  
🔥 Ranking de tópicos mais discutidos  
📊 Dashboard com indicadores do fórum  

## 📊 Dashboard e KPIs
A dashboard do GameLoop foi desenvolvida para fornecer uma visão geral da atividade do fórum, permitindo analisar:  
• Quantidade de tópicos criados  
• Porcentagem de perguntas solucionadas  
• Categorias mais comentados  
• Participação dos usuários  
Esses dados ajudam a entender o comportamento da comunidade e identificar tendências dentro do fórum.  

## 🛠 Tecnologias
Frontend: HTML, CSS, JavaScript  
Backend: Node.js  
Banco de Dados: MySQL  
Visualização de Gráficos: Chart.js
