# Gameloop - fórum
Gameloop é um fórum focado para desenvolvedores de jogos e tem como objetivo fomentar uma comunidade de aprendizagem colaborativa.

## Funcionalidades
Gameloop apresenta ferramentas como publicação de textos, respostas e resolução das perguntas. O fórum possui uma mecânica que filtra nas dúvidas ativas dos usuários e também um ranking dos principais assuntos mais comentados pela comunidade, e aliado à isso, também foi implementado uma dashboard que tem como principais KPI’s acompanhar a média de dúvidas resolvidas e o engajamento dos usuários.
